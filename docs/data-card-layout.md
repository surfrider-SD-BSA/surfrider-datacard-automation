# Beach Cleanup Data Card — Form Layout Reference

This document describes the physical layout of the Surfrider Foundation beach cleanup data card. Use this as a visual reference when reading scanned PDFs.

## Overview

Each volunteer receives a **2-page form** (front and back of a single sheet):
- **Page 1 (Front):** Header fields + Plastic, Personal Care, and Smoking/Tobacco sections
- **Page 2 (Back):** Fishing/Marine, Plastic (Other), Glass/Ceramic, Paper/Wood, Metal, Rubber/Latex, and Other Materials sections

## Page 1 (Front)

### Header Area (Top of Page)

The top of the form has fields for:
- Volunteer name
- Club / Chapter
- Date of cleanup
- Shoreline / Beach name
- Number of volunteers (usually only on the leader card)
- Pounds of trash collected
- Duration

**Note:** Not every volunteer fills in all header fields. The cleanup leader's card usually has the most complete header information.

### Pre-Printed Summary Box (Upper Right)

Every data card has a small box in the upper-right corner showing the numbers **74, 16, 3, 8** under headings like "Common Items" and "Priority Items." These numbers are **pre-printed on the form template** and appear identically on every card across all events. They are NOT volunteer data. **Ignore this box entirely.**

### Data Grid

The main body of the form is a grid with:
- **Item names** in the left column
- **Tally columns** in the middle (for making tally marks: ||||)
- **TOTAL column** on the right (for writing the numeric total)

Some volunteers fill in the TOTAL column with a number. Others only make tally marks in the grid. The TOTAL column is the most reliable source of data when present.

## Reading Tips

### TOTAL Values vs. Tally Marks

- **Best case:** Volunteer wrote a clear number in the TOTAL column (e.g., "46"). Use this value directly.
- **Common case:** Volunteer made tally marks (groups of 5: ||||) and may or may not have written a total. If a total exists, use it. If not, count the tallies.
- **Tricky case:** The number "11" looks identical to two tally marks "||". If the card uses TOTAL values elsewhere, "||" in the TOTAL column is probably "11".

### Common Handwriting Ambiguities

| What you see | Could be | What to do |
|-------------|----------|-----------|
| Rounded digit, unclear | 6 or 8 | Flag as MEDIUM confidence |
| Rounded digit, unclear | 4 or 8 | Flag as MEDIUM confidence |
| Two vertical strokes | 11 or \|\| (two tallies) | Check card type — TOTAL cards mean "11" |
| Compact two-digit number | 50 or 25 | Flag as LOW confidence with both alternatives |
| Very light pencil marks | 1 or stray mark | Flag as LOW confidence |
| Mark near cell border | Item A or Item B | Verify which row it belongs to |

### Blank vs. Zero

- If a row is completely blank (no marks, no number), the value is 0 — do not record it
- If a row has a "0" written in it, record it as 0 (this is rare but valid)
- If you're not sure whether a mark is intentional or a stray pencil mark, flag it
